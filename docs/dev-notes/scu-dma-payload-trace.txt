SCU DMA payload trace
====================

The SDL application can record actual SCU DMA destination writes for a bounded
bus-address interval during a deterministic frame capture. Enable debug tracing,
request a memory dump, and provide both ends of the half-open interval:

    --debug --capture-boot-frames 13096 --dump-memory \
    --trace-scu-dma-payload-begin 0x05C01000 \
    --trace-scu-dma-payload-end 0x05C01020

The capture writes `scu-dma-payload-trace.csv` and
`scu-dma-payload-trace-bundle.txt` beside the other memory dumps. Each CSV row
records a transfer sequence number, SCU channel, destination bus address, write
width in bytes, and the value passed to the bus. Values are numeric; use the
recorded width and Saturn bus byte order when reconstructing bytes. A write is
recorded only after Ymir has issued it to the bus. Writes to the VDP1 register
range that the SCU implementation suppresses are therefore not reported.

Capture requires `--debug`, a nonzero frame count, `--dump-memory`, and a
nonempty address interval. At most 1,000,000 matching writes are retained. The
bundle records the interval, retained and dropped row counts, and whether the
trace is complete; a trace with dropped rows must not be used as complete
transfer evidence.
